# GoldLedger · 工作区

《魔兽世界：无限》(WoW Forever / 客户端 1.60.1) 插件项目。当前主线：**GGS v0.11.5 国服汉化验收与上架准备**；自研插件 `GoldLedger/` 保留在 `自研插件/`。

- 建立日期：2026-10-11
- 游戏上线：2026-11-04（国服 beta 10/06–10/26 删档）——**现在是窗口期，插件生态尚未定型**
- 工作区整理：2026-10-21（按工作流分组；文档相对链接已同步修正）

## 项目是怎么变成现在这样的

原本的计划：自制一个类似 tdinspect 的鼠标提示框插件，在 tooltip 里显示其他玩家的「金币可疑程度 / RMT 相关度」。

调研中发现**同目录下的 `归档/旧版本/GrimlightGoldScanner-v0.9.5/` 已经完整实现了这个设想**——7411 行 Lua，已迭代到 v0.9.5，功能覆盖比原设想更全（金币来源七分类、收入覆盖率、一致性评分、活动度、历史追踪）。

于是方向调整为：**先装上评估，摸清无限客户端到底暴露了哪些数据，再决定做什么。**

## 三条硬事实（省得重查）

1. `## Interface: 16001`，`## AllowLoadGameType: camelot`。客户端基于 **Mainline 代码库**，12.0 的 API 都在，只是被 camelot 规则关掉
2. **看不到其他玩家的当前金币**；他人的**历史最大金币**可以经成就统计对比拿到。这条链路**正被人请求暴雪关闭**
3. 机密值闸门 `ShouldUnitComparisonBeSecret(unit1, unit2)` 决定第 2 条这条路通不通

细节见 [02-技术情报.md](调研资料/02-技术情报.md)；风险见 [04-先例与政策风险.md](调研资料/04-先例与政策风险.md)。
