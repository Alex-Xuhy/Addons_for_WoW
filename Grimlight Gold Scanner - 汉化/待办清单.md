> - 好处：改工作区即改插件，git 能跟踪所有改动，无限工坊的热加载也能直接生效
> - 删的时候删联接本身即可，不会动到工作区的文件

### GoldLedger（自制的）

| 命令                     | 作用                                                       |
| ------------------------ | ---------------------------------------------------------- |
| `/gl ping`             | 诊断：客户端版本、Interface 号、对比接口与统计发现的可用性 |
| `/gl ids`              | 十个统计量的绑定情况 ← **最常看的一条**             |
| `/gl probe [关键词]`   | 列出客户端返回的**全部**统计量（ID + 名称）          |
| `/gl names [关键词]`   | 只列名称，用于核对本地化                                   |
| `/gl set <key> <id>`   | 手动绑定统计量                                             |
| `/gl reset`            | 清除手动绑定并重新识别                                     |
| `/gl export`           | 导出手动绑定（备份用）                                     |
| `/gl me`               | 自己角色的账                                               |
| `/gl scan`             | 扫描当前目标（最多等 15 秒）                               |
| `/gl hover on\|off`     | 悬停扫描开关（默认开）                                     |
| `/gl hoverself on\|off` | 悬停自己时也显示（默认关）                                 |
| `/gl tip on\|off`       | tooltip 里的免责声明（默认开）                             |
| `/gl retain on\|off`    | 留存档案开关（**默认关**）⚠️                       |
| `/gl clear`            | 清空会话缓存                                               |
| `/gl help`             | 全部命令                                                   |
