## 4. 评分机制优化/本地化（大头）

### 4.1 ① 国服情况叙述 + 一致性评分权重调整

- **4.1.1 ✅ 国服环境**：GDKP、散人、世界团/流水团远多于美服；GDKP 结算走玩家间直接交易，不入分项计数器。
- **4.1.2 ✅ 覆盖率结构性失真**：合法卖方也会低覆盖 + 大缺口；919 缺失进一步压低覆盖率。
- **4.1.3 ✅ 覆盖率定位**：它是「清白证据」的好口径（高覆盖值得加分），不是「嫌疑」的好口径（国服低覆盖是常态）。
- **4.1.4 ✅ 覆盖率降权 + 非对称**：高覆盖可加分；低覆盖在结构性缺失时中性；计数器结构性不可用 → 因子弃权 + 降置信度，而非低分。
- **4.1.5 ✅ 等级财富升为主权重**：RMT 买家进团本前必持大量金币，是最直接的买方证据；但**先修基准再提权重**。
- **4.1.6 ✅ 基准加固**：`peerMin` 3 → **10**（满级 20）；固定 2×/10× → log-ratio + 百分位；绝对额下限；悬停显示 n / 中位数 / IQR；**满级独立池**（±5 级不再混入 55–59）。
- **4.1.7 ✅ 无法解释上涨**：保持次权重；GDKP **卖方**也产生「大额上涨未由分项解释」，报告需注明。
- **4.1.8 ✅ 权重起始值**：覆盖率 **10**、无法解释上涨 **25**、等级财富 **30**、活动度 **25**、本人往来 **10**。
- **4.1.9 ✅ 底线**：打击并揭露 RMT 不变；「无法解释 ≠ RMT 证据」保留。
- **4.1.10 🔶 待你定**：覆盖率 **10 vs 5**；活动度 **25 vs 30**。

### 4.2 ② 高级骑术/千金马储蓄者 + 你的思路

- **4.2.1 ✅ 问题**：无限服贵在**骑术**（~1000G），不是坐骑；合法储蓄者峰值 ~1000G，单轴上与 GDKP 买方几乎不可区分。
- **4.2.2 ✅ 你的想法①（商人交易）**：支出能否统计与商人的交易？→ 当前统计清单**没有**「向商人购买花费」；`921` 是「向商人出售所得」；他人不可观测；只能对自己做钱包差；问作者是否有路径。
- **4.2.3 ✅ 你的想法②（高级骑术）**：能否识别玩家已学高级骑术？→ 无 `InspectSkill` API；`mounts = 339`「获得坐骑数量」是弱代理（可读性待查）；当前持有金币只对自我可见；仓库小号可分散金币。
- **4.2.4 ✅ 你的想法③（峰值阈值）**：可配置「合法储蓄上限」1200–1500G；储蓄者到 ~1000G 会马上消费学骑术，只有工作室/RMT 继续囤积；超过上限后峰值恢复识别力；**软阈值**，不硬切。
- **4.2.5 ✅ 经济不确定性**：若只有少部分人买得起 → 用活动度/第二轴补偿峰值失真；若多数人金币都多 → 千金马对峰值影响反而变小。
- **4.2.6 ✅ 第二轴**：单轴不可区分 → 财富 × 活跃二维；这是第二轴的理由。
- **4.2.7 ✅ 回复位置**：短邮件 **4(b)**、提案 **4.2**（你的三条思路全部写入）。
