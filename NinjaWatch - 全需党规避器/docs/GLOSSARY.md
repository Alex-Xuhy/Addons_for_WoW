# 术语表

按用户要求：每个自造指标都写清“怎么算的 / 量纲 / 大小意味着什么”。外部 API/字段也一并列出，避免下次重新猜定义。

## 核心指标

| 术语 | 怎么算 | 量纲 | 大小意味着什么 |
|---|---|---|---|
| **Need（需求次数）** | 客户端终身统计 `1044`：Need rolls made on loot | 次（整数） | 终身选“需求”的次数；受活动量影响，不能单独当异常 |
| **Greed（贪婪次数）** | 客户端终身统计 `1043`：Greed rolls made on loot | 次（整数） | 终身选“贪婪”的次数；越小越可能是放弃派，或越可能只需求 |
| **E（进入次数）** | 客户端终身统计 `932`：Total 5-player dungeons entered | 次（整数） | 进入 5 人本的次数；**不是团本、不是完成数**。当前样本中位 5、最大 53 |
| **R（总掷骰）** | `R = N + G` | 次（整数） | 终身参与 Need/Greed 的总次数；不含 Pass，也不含未参与 |
| **N/R（需求占比）** | `N / R` | 比例（0–100%） | 在记录到的 Need+Greed 里 Need 占多少。**不是概率，也不含 Pass**；34.6% 就是 34.6% |
| **N/E（每趟需求）** | `N / E` | 次/次进入 | 每进一次 5 人本平均需求几次；只作参考列，**不是判据** |
| **R/E（每趟总掷骰）** | `R / E` | 次/次进入 | 每进一次本平均参与几次 Need/Greed；含世界练级/组队 roll，所以不是“纯副本 roll” |
| **q_lo** | 常数 5.4 | 次/次进入 | 正常玩家 `R/E` 的保守下界先验；**不是 p10**（当前主样本约 p23） |
| **L(E)（下界）** | `q_lo × E = 5.4E` | 次（整数/小数） | 一个正常玩家 E 次进入至少应有多少次 Need+Greed；是“正常玩家实际 R 的下界”，不是总掉落件数 |
| **gap（缓冲）** | `max(3, 0.15 × L(E)) = max(3, 0.81E)` | 次 | 政策余量，不是置信区间；15% 是相对容忍，3 次是小数样本保护 |
| **T(E)（门槛）** | `L(E) − gap` | 次 | `E≤3`：`5.4E−3`；`E≥4`：`4.59E`。`R<T` 判放弃派 |
| **放弃派（pass-type）** | `R < T(E)` | 类别 | 很少参与掷骰（大量 Pass）的正常玩家；整类放行，不评估 N/R、不报警 |
| **贪婪派（greed-type）** | `R ≥ T(E)` 且 `E≥4` | 类别 | 参与掷骰足够多，进入 N/R 档位；不等于“全需党” |
| **档位** | `N/R`：`<10%` 深绿；`10–<50%` 绿；`50–<70%` 黄；`≥70%` 红（且 `R≥30`） | 类别 | 低=几乎不需求；正常=多数玩家；偏高=Need 过半；极高=Need 压倒性 |
| **红档封顶** | `N/R≥70%` 且 `20≤R<30` → 黄 | 类别 | 小样本证据不足，不升级为红；`R<20` 先判灰 |
| **比率灰** | `R<20` | 类别 | Need+Greed 太少，比率不稳，不判档 |
| **筛查灰** | `E<4` | 类别 | 放弃派门槛样本不足，整行“样本不足” |
| **p05/p10/p15/p18/p20/p50/p90** | 把样本排序后第 5/10/15/18/20/50/90 百分位 | 同原指标 | 用来看 5.4 在分布里的位置；分位随样本口径变化，必须写明 universe |
| **主样本（main）** | `E≥4` 且 N/G/E 可读、`R>0` | 类别 | 当前 68 行；放弃派筛查的实际适用人群 |
| **低 G 子集** | `G/R ≤ 10/20/30%` | 类别 | 用来估“放弃派的 N/E 上界”；当前主样本 0 行，无法估计 |
| **高 N/R 子集** | `N/R ≥ 50/60/70%` | 类别 | 用来检查放弃派筛查是否把高 N/R 的人误放行；当前 ≥50% 有 3 人，其中 2 人判放弃派 |

## 统计与判定

| 术语 | 含义 |
|---|---|
| **单侧 95% 下界（Clopper–Pearson）** | 给定观测 `N/R` 与 `R`，真实需求占比的 95% 置信下界；`R=30` 时 70% 线的下界约 53.5%，50% 线约 33.9% |
| **p 值/显著性** | 本插件不做显著性检验；档位是预警分级，不是统计判决 |
| **自然断点** | 数据分布里明显的空隙；当前 N/R 分布单峰，最大空隙 39.1%→49.4%，**70% 不是自然断点**，是政策线 |
| **误报** | 正常玩家被标为偏高/极高；放弃派筛查、`R≥30`、灰线用于降低影响 |
| **漏报** | 全需玩家未被标出；例如高 N/R 但 `R` 很低的人会被判放弃派（当前样本 2 人） |
| **必要条件** | 全需党不会大量 Pass，所以“放弃派”可直接排除；反过来不成立：贪婪派不等于全需党 |

## 数据与接口

| 术语 | 含义 |
|---|---|
| **终身计数** | 角色从创建至今累计的计数；不是本场、不是本次副本、不是本周 |
| **按次数据** | 只描述某一次掉落/某一场的掷骰；不能与终身计数相加或相除 |
| **Pass（主动放弃）** | `C_LootHistory` 的 `Pass=5`；表示玩家主动选择放弃。**没有终身 Pass 统计** |
| **NoRoll（未掷骰）** | `C_LootHistory` 的 `NoRoll=4`；表示未参与/未看到/掉线/超时等，**不算主动放弃** |
| **`C_LootHistory`** | 暴雪按次战利品历史 API；状态含 NeedMainSpec/NeedOffSpec/Transmog/Greed/NoRoll/Pass；v1 不使用 |
| **`--`** | 统计文本为 `--`：表示 0/未记录，不是 API 失败；插件按 0 读，但 quality 记为 `zero` |
| **缺失/secret** | 返回 nil 或被 secret 包裹：表示未知，**绝不按 0** |
| **比较接口** | `SetAchievementComparisonUnit(unit)` + `INSPECT_ACHIEVEMENT_READY` + `GetComparisonStatistic(id)`；读取他人统计的路径 |
| **自己的统计** | `GetStatistic(id)`；只对自己有效 |
| **GUID** | 玩家唯一标识；数据库按 GUID 去重，显示时用名字；不外传 |
| **SavedVariables** | 插件退出/重载时保存的本地变量；`NinjaWatcherDB` 存在这里 |
| **TOC** | 插件清单文件，含 `## Interface`、`## Title`、`## SavedVariables` 等 |
| **Interface 号** | 客户端接口版本；不匹配会显示“过期”；当前用 `16001`，与 GGS 一致 |
| **AddDoubleLine** | `GameTooltip:AddDoubleLine(left, right, ...)`；用于左右两端对齐的一行提示 |
| **TooltipDataProcessor** | 暴雪提示框后置回调；用于在悬停单位时追加行，不覆盖其他插件 |
| **枚举缺口** | GGS 只调用 `GetCategoryNumAchievements(cat)`，失败才用 `(cat,true)`；且跳过 `skip=true`；因此 `row.all` 缺失不等于客户端没有 |
| **GGS** | Grimlight Gold Scanner，已安装的参考插件；All Rights Reserved，只读参考，不复制代码 |

## 产品/交互

| 术语 | 含义 |
|---|---|
| **玩家目录** | 设置页中的玩家列表；显示历史扫描结果，可排序、清除 |
| **选项页** | 设置页中的开关页；控制提示、自己提示、黄档本地、红档 `/p` |
| **悬停提示** | 鼠标移到玩家模型/头像时追加的两行：比率+档位、样本 |
| **入队报警** | 玩家加入 5 人小队或小队进新成员时触发检查 |
| **偏高（黄）** | `N/R 50–<70%`；本地聊天框，仅自己可见 |
| **极高（红）** | `N/R≥70%` 且 `R≥30`；默认只本地；开关开启时 `/p` 一次 |
| **冷启动** | 插件首次安装/数据库为空时，是否从 GGS 缓存导入；v1 不导入 |
| **`/nw test`** | 跑 `Rate.SelfTest()` 的 14 个边界用例 |
