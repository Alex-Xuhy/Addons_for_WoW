## 7. 旧 Phase 0 数字（已作废，留痕）

旧口径 `n=N+G≥20`、未做放弃派筛查，曾得到：90 行、需求率中位 17.0%、p90 33.3%、p95 44.8%、max 75.0%；档位低 19/正常 67/偏高 3/极高 1。

作废原因：

1. 分母混入了放弃派（大量 Pass 的人 N/R 天然偏高）。
2. `n>=20` 与 `E>=4` 不是同一 universe。
3. 75.0% 的极端行 `G=5`，在新规则下 `R/E` 很低，整行判放弃派、不评估。

这些数字只用于说明“为什么旧方案会误判”，不再作为参数依据。

## 9. 数据局限

1. **非随机样本**：GGS 用户/被扫描者，偏向特定服务器、等级段、玩法。
2. **只有 11–30 级**：Beta 删档测试；不能外推满级。
3. **缺失非随机**：62 行不可读；不能当 0。
4. **终身计数 vs 当前等级**：玩家可能升级/转服/改名，等级与终身计数不完全匹配。
5. **无 Pass 分母**：N/R 天然高估“全需”程度。
6. **低 G 子集为 0**：无法数据化估计放弃派上界。
7. **`932` 口径待正式服复验**：当前按“5 人本进入次数”使用。
