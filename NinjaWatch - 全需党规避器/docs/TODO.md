# 待办清单

按优先级排序。P0 是下一步必须做的；P1 是上线前；P2 是上线后校准；P3 是发布。每项写明依赖和完成标准。

## P0：游戏在线后立即做

### T-001 安装并加载

- **做什么**：把 `src/` 复制为 `Interface/AddOns/NinjaWatcher/`（只复制 `src/`，文件夹名与 `.toc` 同名）。
- **依赖**：游戏关闭 → 复制 → 完整重启（新文件/`.toc` 变更不能只 `load`）。
- **完成标准**：插件列表出现 NinjaWatcher；`/nw status` 有输出；无 Lua 报错。

### T-002 静态场景验证

- **做什么**：`check` → `load` → `try`（只读场景）→ `snap`。
- **完成标准**：`check` 0 error；`load` ok；无 blocked/taint；`snap` 能看到设置页。
- **注意**：`run`/`try` 不发聊天、不打开暴雪面板、不注册受限事件。

### T-003 规则自测

- **做什么**：游戏内 `/nw test`。
- **完成标准**：14 个边界用例全部通过；`/nw status` 显示自己的 N/G/E/R 与判定。
- **覆盖**：`E<4` 灰、`R<T` 放弃派、`R=T` 贪婪派、`R<20` 比率灰、`R<30` 红档封顶、50/70 边界。

### T-004 扫描与提示

- **做什么**：鼠标指向自己、队友、NPC、远处玩家；观察提示行。
- **完成标准**：
  - 自己走 `GetStatistic`，不触发对比接口；
  - 队友扫描成功后提示 `需求率 xx% · 档位` + 灰色样本行；
  - 连续悬停多人不重叠请求（1.5s 间隔）；
  - 原生 `AchievementFrameComparison` 不被我们的请求弹出，或弹出后立即隐藏；
  - 战斗、超时、远距离有明确状态。

### T-005 入队报警与设置页

- **做什么**：组 5 人队；观察黄档本地提示；手动开启红档 `/p` 后观察一次发送与冷却。
- **完成标准**：
  - 团队/单人/战场不误触发；
  - 4 人→5 人时老成员补扫并评估；
  - 黄档只本地；红档仅在开关开启时发一次 `/p`；
  - 设置页两页可开；四个开关重载后保留；清除全部两次确认。

## P2：上线后校准

### T-020 定期跑标定

- **做什么**：`py -I analysis/calibrate_pass_ratio.py`；看 `latest.md`。
- **完成标准**：每次样本显著变化后有一份新报告；`pass_ratio_history.csv` 可追溯。
- **注意**：脚本不自动改代码；改动须人工复核。

### T-021 低 G 样本

- **做什么**：等主样本 `G/R≤10%` 达到 ≥20 行，估放弃派上界。
- **完成标准**：报告给出低 G 子集 N/E 分位；与 5.4 比较后决定是否替换。

### T-022 满级样本

- **做什么**：收集满级玩家数据，重算 `R/E` 分位、档位命中率、`E` 分布。
- **完成标准**：给出满级 `q_lo` 候选与档位占比；与 Beta 参数对比。

### T-023 `932` 口径复验

- **做什么**：确认正式服 `932` 仍是“5 人本进入次数”，未改成完成数/首领击杀。
- **完成标准**：与成就描述一致；若口径变化，重估 `q_lo`。

## 暂缓/不做

| 项 | 状态 | 原因 |
|---|---|---|
| 终身 `Pass` 统计 | 暂缓 | 当前客户端没有；不猜接口 |
| `C_LootHistory` 按次 Pass | 暂缓 | 按次口径，不能混入终身分母 |
| 两次扫描增量 | 暂缓 | 用户明确暂时不做 |
| 跨甲/跨天赋/A/N 判断 | 不做 | 数据不可得且有争议 |
| 右键菜单/小地图/独立窗口 | 不做 | 与轻量化冲突 |
| 绝对 Need 同级阈值 | 不做 | 旧方案已废止，由放弃派筛查 + N/R 取代 |
| 活动量协变量/分层 | 不做（v1） | `E` 已直接进门槛；代理误差 3–4.5 倍 |
| 从 GGS 缓存冷启动 DB | 待定 | 涉及隐私与口径；需用户拍板 |
| 自动应用标定结果 | 不做 | 必须人工复核 |
