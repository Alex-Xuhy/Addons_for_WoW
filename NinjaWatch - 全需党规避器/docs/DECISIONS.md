## 被否决/搁置的方案

| 方案 | 状态 | 原因 |
|---|---|---|
| 把 `Pass` 加入分母（`N/(N+G+Pass)`） | 否决 | 无终身 Pass 统计；按次 Pass 不可比 |
| 把 `NoRoll` 当 Pass | 否决 | 语义不纯，会把掉线/未参与算成主动放弃 |
| 用总击杀精确倒推总掷骰次数 | 否决 | 比率 p10–p90 约 3 倍，误差太大 |
| 用 GGS 的 `row.all` 缺失证明客户端没有 1103/1467 | 否决 | GGS 枚举可能漏 hidden/superceded 项；需原始 API 探针 |
| 直接拿等级段中位数当预警线 | 否决 | 会命中约一半玩家 |
| 右键头像菜单/独立窗口/GGS 皮肤 | 否决 | 与轻量化目标冲突 |
| 用 p10=3.12 作 q_lo | 否决 | 致命假阳性（D-029） |
| 用 5.4 但不加 gap | 否决 | 用户拍板保留缓冲（D-030） |
| 把 `L(E)<20` 当灰线 | 否决 | 与 q_lo 耦合，换 q_lo 会漂移（D-031） |
| 自动应用标定结果 | 否决 | 样本非随机、口径会变；必须人工复核（D-036） |
