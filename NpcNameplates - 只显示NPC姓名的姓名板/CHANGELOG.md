# 更新日志

## 0.7.0 — 2026-10-23

- 设置页全部内容改为滚动区：内容再多也不会溢出设置面板，滚动查看。
- 新增「靠近放大」开关：可关闭客户端「走近 NPC 时放大姓名板」的行为。
- **配置全部插件化**：所有设置只保存在插件存档 `NpcNameplatesDB`；
  「姓名板堆叠」「靠近放大」改用客户端临时值（不写入游戏配置文件），
  卸载插件后游戏立刻恢复原生。
- 新增 `/nn` 作为设置入口（`/nnp` 仍然可用）。
- 从 0.6.0 升级时，会把旧版写进客户端的「靠近放大」缩放值还原一次，
  再把当时的开关状态记成插件设置继续生效。

## 0.6.0

- 新增「姓名板堆叠」开关。
- 插件显示名改为 NpcNameplates。
