## ① NGA 帖子

**标题：** 【原创】NpcNameplates 0.7.0 —— 让 NPC 姓名板只显示名字（1.60.1）

**正文：**

玩久了总会觉得，NPC 头顶那一坨血条、等级、精英标记和光环图标太吵。暴雪原生只给了「友方玩家」的
「仅显示名字」选项，NPC 没有。

这个插件补的就是这块：**友方、敌方、中立 NPC 的姓名板都只留名字**，其余部件全部隐藏，施法条保留。
名字下方还可以带一行 `<头衔>`（比如 `<锻造供应商>`），字号、位置、三种阵营的颜色都能自己调。

**效果**

- 只显示名字，不显示血条、血量数字、等级、精英标记、光环
- 施法条保留（打怪看读条不受影响）
- 可选 `<头衔>` 行，没有头衔的 NPC 不显示
- 友方 / 敌方 / 中立 三种颜色各自可调（默认 亮绿 / 深红 / 黄）
- 玩家姓名板、玩家自己的宠物和图腾完全不受影响

![效果对比：左为原生，右为插件](#)

**两个额外开关**

- **姓名板堆叠**：就是系统「设置 → 姓名板 → 堆叠姓名板」那个开关，放进插件设置里方便一起调。
- **靠近放大**：客户端默认会在你走近 NPC 时把姓名板放大（近距离 1.00 倍、远距离 0.80 倍）。
  如果不喜欢这种忽大忽小，可以在这里一勾关掉，远近保持同一倍率。

**安装**

解压后把 `NpcNameplates` 文件夹放进 `Interface\AddOns\`，重进游戏即可。不需要任何依赖。

**怎么打开设置**

`设置 → 插件 → NpcNameplates`，或者在聊天框输入 `/nn`（`/nnp` 也可以）。
输入 `/nn status` 可以看当前处理了多少个姓名板。

**关于「卸载干净」**

这一点特意做了处理：插件**不往游戏配置文件里写任何设置**。
所有选项只保存在插件自己的存档里；「姓名板堆叠」「靠近放大」两个开关用的是客户端临时值，
只在本次游戏里生效，不写 `Config.wtf`，退出就消失。
所以**直接删掉插件文件夹，游戏立刻回到原生状态**，不用清配置、不用改回去。

**常见问题**

- 友方 NPC 不显示？先在 `设置 → 姓名板` 里勾上「友方NPC姓名板」。
- 没有 `<头衔>`？少数 NPC 本身没有副标题，这一行会自动省略。
- 和别的姓名板插件冲突？本插件只改 NPC 姓名板的部件显示，不与玩家姓名板插件抢同一批单位；
  如果同时装了其它姓名板美化，建议只留一个。

**兼容性：** WoW Forever 1.60.1（Interface 16001 / camelot）。其它版本未测试。

欢迎回帖反馈问题，尽量带上截图和复现步骤。

## ② 新手盒子 插件详情

**插件名称：** NpcNameplates

**版本：** 0.7.0

**适用客户端：** WoW Forever 1.60.1（Interface 16001）

**类别：** 界面增强 / 姓名板

**简介：**

让友方、敌方、中立 NPC 的姓名板只显示名字，隐藏血条、血量、等级、精英标记与光环，施法条保留。
名字下方可选显示 `<头衔>`，三种阵营颜色、字号、垂直位置均可调。
附带「姓名板堆叠」与「靠近放大」两个客户端开关。
所有设置只存在插件存档里，不写入游戏配置，卸载即恢复原生。

**详细说明：**

暴雪原生只有「友方玩家」的「仅显示名字」，NPC 姓名板没有对应选项。NpcNameplates 把同样的效果
扩展到所有 NPC：

- 只留名字，隐藏血条、血量数字、等级、精英标记、光环；施法条保留
- 可选 `<头衔>` 行（取自单位提示框副标题），字号随名字自动缩放
- 友方 / 敌方 / 中立颜色独立可调（默认 亮绿 #00FF00 / 深红 #8C0000 / 黄 #FFD100）
- 姓名板堆叠开关：与游戏原生「堆叠姓名板」同一数值
- 靠近放大开关：可关闭客户端按距离缩放姓名板的行为
- 玩家姓名板与玩家控制的单位（宠物 / 图腾等）完全不受影响

**安装方法：**

把 `NpcNameplates` 文件夹放入 `Interface\AddOns\`，确认 `Interface\AddOns\NpcNameplates\NpcNameplates.toc`
存在，重进游戏。无任何依赖。

**设置入口：**

`设置 → 插件 → NpcNameplates`，或聊天框输入 `/nn` / `/nnp`。

**卸载说明：**

删除插件文件夹即可。插件不写入游戏配置文件；「姓名板堆叠」「靠近放大」使用客户端临时值，
退出游戏即消失，卸载后游戏立刻恢复原生。
