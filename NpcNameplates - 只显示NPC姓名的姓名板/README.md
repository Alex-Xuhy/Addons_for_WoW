# NpcNameplates — 只显示 NPC 姓名的姓名板

适用于 **WoW Forever 1.60.1**（客户端 Interface 16001，游戏类型 camelot）。

把暴雪只给「友方玩家」的「仅显示名字」同步给 NPC：友方、敌方、中立 NPC 的姓名板都只留名字，
不再显示血条、血量、等级、精英标记与光环；**施法条保留**。

## 功能

- NPC 姓名板只显示名字；字号（默认 17.5）、名字垂直偏移（默认 0）可调
- 名字下方可选显示 `<头衔>` 行（取自客户端单位提示框的副标题；字号为名字的 0.8 倍）
- 友方 / 敌方 / 中立三种阵营颜色各自可调（默认 亮绿 #00FF00 / 深红 #8C0000 / 黄 #FFD100）
- **姓名板堆叠**开关（与游戏原生「堆叠姓名板」控制同一个客户端数值）
- **靠近放大**开关（客户端按距离缩放姓名板；可关闭，远近保持同一倍率）
- 玩家姓名板、以及玩家控制的单位（宠物 / 图腾等）完全不碰

## 安装

把 `NpcNameplates` 文件夹整个放进：

```
World of Warcraft\Interface\AddOns\NpcNameplates\
```

确认这一层能看到 `NpcNameplates.toc`。不需要任何依赖。

## 使用

- 设置：`设置 → 插件 → NpcNameplates`
- 聊天框输入 `/nn` 或 `/nnp` 直接打开设置
- `/nn status` 输出当前姓名板计数

## 配置与卸载

- 所有设置只保存在插件自己的存档 `NpcNameplatesDB` 里，**不写入游戏配置文件**。
- 「姓名板堆叠」「靠近放大」两个开关使用客户端临时值（`SetTempCVar`）：只在本次游戏进程内生效，
  不写入 `Config.wtf`，退出即消失。注意：如果只是禁用插件并重载界面、不退出游戏，
  这两个临时值可能保持到本次游戏结束；重进游戏即恢复原生。
- 因此**直接删除插件文件夹即可**，游戏立刻恢复原生状态，不需要任何清理。
  `WTF` 里残留的 `NpcNameplatesDB` 文件不再起任何作用；想彻底清干净可手动删除。
- 两个客户端开关在插件启用期间由插件接管；想让游戏原生设置重新生效，点设置页的「恢复默认」。

## 已知限制

- 头衔取自客户端单位提示框的第二行；个别 NPC 没有副标题时不显示 `<头衔>`。
- 友方 NPC 的姓名板需要游戏里已开启（`设置 → 姓名板 → 友方NPC姓名板`）。
- 玩家姓名板的显示方式不受本插件影响。
